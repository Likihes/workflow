🔸 Types of Reset

1. Soft (keeps changes staged)
git reset --soft HEAD~1

👉 Removes commit, but keeps code in staging

2. Mixed (default)
git reset HEAD~1

👉 Removes commit, keeps code unstaged

3. Hard (dangerous 🚨)
git reset --hard HEAD~1

👉 Deletes commit + code completely

---------------------

🔹 DevOps Real Scenario
❌ Wrong deployment pushed
Use:
git revert <commit-id>
git push

👉 Safely rollback production

❌ Local mistake before push
Use:
git reset --soft HEAD~1

👉 Fix commit and recommit
